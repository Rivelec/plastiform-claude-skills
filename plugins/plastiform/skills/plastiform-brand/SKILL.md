# Plastiform brand

Plastiform is a trademark of **Rivelec**. Tagline: *"Stop destroying your parts. Use Plastiform."*

## The one rule

Pull EVERY product name, spec, number, claim, and offer from the brand knowledge base.
If a fact isn't in a source, **don't write it — find it or ask.**

Source of truth (in the marketing repo): `.specify/memory/brand-knowledge/`
(`company` / `products` / `technology` / `applications` / `glossary` + `do-not-invent.md`).
Voice is governed separately by `.specify/memory/brand-voice.md`.

## Real anchors (safe to state)

- Fidelity ~±1 µm.
- **DN1 degrease before every impression.**
- Real guns: DM / DP / DB-50 and -400.
- "Mallette" = real kit codes (ML-040, …).

## Never invent (previously flagged as fabrications)

- A "Plastiform Academy" — doesn't exist. Real training = a Vincent Majeau Calendly demo,
  YouTube `@plastiform-by-rivelec`, the Resource Center, and the blog.
- Any DM-50 → DB-50 trade-in / "reprise" program.
- Discount codes (e.g. TRADEIN15 / MALLETTE30 / RESTOCK20) or a "Mallette –30% welcome offer".
- A "Bulk XL format".
