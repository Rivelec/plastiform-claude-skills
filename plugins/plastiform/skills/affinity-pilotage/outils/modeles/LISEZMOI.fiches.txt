CONTENU DU DOSSIER
  {{BASE}}             Mise en page commune à toutes les langues : photos, pictos, fonds, valeurs techniques.
                       AUCUN texte de langue.
  {{FICHIERS_LANGUES}}
                       Textes de la langue ; la BASE est placée en lien sous chaque planche.
  projet.json          Découpage en fiches (titre repère, référence et version imprimées), titres des PDF.
  Images/              Toutes les images, LIÉES (jamais incorporées). Ne pas renommer un fichier.
  Fonts/               Polices du projet (à installer sur le poste).
  Scripts/             Script d'export (utilisable depuis n'importe quel poste).
  {{EXPORTS}}          PDF : un par fiche et par langue ({{EXPORTS}}Fiches/<langue>/) + journal export_log.txt.
  CHANGELOG.md         Historique : une section par fiche, avec sa version.

OÙ MODIFIER QUOI
  - Une photo, un picto, une valeur technique, la mise en page -> BASE (une fois pour toutes les langues), puis
    enregistrer : les fichiers de langue la reprennent à leur prochaine ouverture.
  - Un texte, une traduction                                     -> fichier de la langue.
  - La version d'une fiche                                       -> son pied de page, dans CHAQUE langue
                                                                    (« Version X.Y » ; « Versión X.Y » en espagnol).

RÈGLES
  - Insérer une image : Fichier > Insérer…, depuis Images/, avec le placement « Lié » (Fichier > Configuration du
    document > Placement des images : Préférer lié). Jamais de copier-coller d'image (elle serait incorporée).
  - Insérer la BASE dans un fichier de langue : décocher « Remplacer existant » dans la barre d'outils.
  - Pas de calque pixel peint : exporter le visuel retouché dans Images/ et le placer lié.

EXPORTER LES PDF
  1. Ouvrir dans Affinity un fichier de langue ou la BASE.
  2. Fenêtre > Exécution de scripts > Bibliothèque : « Export par élément » (ou ouvrir Scripts/export_par_element.js
     dans l'éditeur de script) > Exécuter. Toutes les langues présentes sont exportées ; les fichiers ne sont jamais
     enregistrés (un fichier déjà ouvert est exporté tel qu'il est affiché, modifications non enregistrées comprises).
  3. Résultat : {{EXPORTS}}Fiches/<langue>/<référence>_V<X>-<Y>.pdf — nom tiré de la référence et de la version
     imprimées sur la fiche — + export_log.txt.
  Prérequis (une fois par poste) : Réglages > Exécution de scripts : activer l'exécution, cocher « Accéder au
  système de fichiers », ajouter ce dossier à la liste.

MONTER LA VERSION D'UNE FICHE
  1. CHANGELOG.md, section de la fiche : « ### Non publiée – Version X.Y » (ou : python3
     _Outils_Affinity/python/projet.py version <ce dossier> --element "F20").
  2. Pied de page de la fiche, dans chaque langue : « Version X.Y ».
  3. Relancer l'export. Fiche publiée : projet.py publier <ce dossier> --element "F20".
